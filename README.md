### 👨‍💻 _Sobre o meu trabalho_

> **A tecnologia só faz sentido quando resolve problemas reais.**  
> Sou **Rafael Maia**, desenvolvedor focado no **Back-end** e atualmente cursando o **6º semestre de Sistemas de Informação**. 
> 
> Minha paixão está na base das aplicações: arquitetar lógica, estruturar banco de dados, criar integrações via API e automatizar rotinas. Combinando minha vivência prática em gestão de processos na administração pública com meus estudos técnicos diários, desenvolvi uma visão crítica para escrever **código limpo, seguro e escalável**.
>
> 🚀 **Objetivo Atual:** Conquistar minha primeira oportunidade de **estágio** para aplicar meus conhecimentos em Python, Bancos de Dados e conteinerização em um ambiente de produção dinâmico.
